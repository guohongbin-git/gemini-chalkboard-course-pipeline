# 出图 Prompt 模板

## 固定构图（所有板图共用）

```
画一张黑板风插画:墨绿色黑板背景,白色粉笔手绘线条,笔触带轻微手绘不完美感;
黄色/蓝色粉笔只做少量点缀;画面大量留黑不要填满;
绝对禁止任何文字、字母、数字、汉字笔画、似字纹理;
所有「空白」区域必须是完全空白的气泡/便签/线框。16:9 横版。
构图固定:主体放在画面左下角区域,画面中央一个大的空白对话气泡(完全空白),
画面右侧一个空白大方框,气泡下方一条黄色粉笔下划线,
一条蓝色粉笔箭头从主体指向右侧方框。
主体:<本讲概念的可视化隐喻,零文字>
```

- 文字一律后贴（Remotion 槽位渲染），图里出现任何似字纹理即重出
- 「主体」每讲 3 条，对应 s03/s04/s05 概念场景
- 同批 md5 防重复：Gemini 偶发返回旧图

## 主体设计经验

- 用具体物品承载抽象概念：事件队列=排队滑落的小卡片+接住的手
- 每个画面 1 个主体 + 固定构图的三件套（气泡/方框/箭头），不要贪多
- 隐喻必须能被旁白复用：图里的「钥匙」就是台词里的「换钥匙」
- 人手画成极简轮廓（无手指细节），避免诡异
- 禁词列表写死在 prompt 里：文字/字母/数字/汉字笔画/似字纹理
