# 课程适配指南（任意学科通用）

这套生产线与「CS106A」零耦合。换一门课，只需四样东西：**spec 剧本、8 张布局板图、每讲 3 张概念板图、一条音色**。粉笔字、时间轴、渲染全部复用。

## 一、舞台文法（学科无关）

每张概念板图都是同一句式，**任何学科通用**：

```
[具体隐喻·左下] —蓝箭头→ [抽象结论·右框]
        ↓提问
  [气泡·中上] + [黄线·强调]
```

- 左下主体：具象的物（文科用船/地图/天平，理科用齿轮/电路/漏斗）
- 气泡 = 提问区，右框 = 结论区，黄线 = 视觉动线
- 图内零文字——所有含义由 Remotion 槽位字幕承载

## 二、8 张布局板的语义槽位（内容全靠字幕定义）

| 板 | 画面 | 学科无关的语义 |
|---|---|---|
| s01 | 讲堂幕布+观众 | 开场：课程名 + 本讲钩子 |
| s02 | 半开的门+三张卡 | 承接：三个并列例子/对比 |
| s06 | 羊皮纸卷+羽毛笔 | 清单：误区/规则/要点 |
| s07 | 大脑齿轮 | 深入：案例/实操/推演 |
| s08 | 火柴人+机器人+箭头 | 收尾：本讲回顾 + 下讲预告 |

s03/s04/s05 是概念位的备用布局（课程可全程用逐讲独立出图替代）。

**换课程不需要重出这 8 张**——画面无文字、无学科符号。想要课程专属风格（如历史课换羊皮纸底、数学课换蓝图底），用同一构图 prompt 换背景词重出即可。

## 三、十类母题库（出图选型用）

78 张概念图的实证收敛。给每讲 3 个概念选母题时，**跨讲轮换、同类不连用**：

| 母题 | 适合的概念类型 | 例 |
|---|---|---|
| 手（指/按/递/抽） | 操作、交互、选择 | 按门铃=监听器 |
| 容器/盒/抽屉 | 存储、封装、作用域 | 标签抽屉=哈希桶 |
| 序列/排队 | 顺序、队列、流程 | 卡片滑落=事件队列 |
| 锁与钥匙 | 权限、加密、匹配 | 挂锁=private |
| 机器/齿轮 | 加工、转换、协作 | 绞肉机=哈希函数 |
| 证书/印章 | 承诺、契约、认证 | 证书=接口 |
| 分叉/汇合路径 | 分支、异常、决策 | 漏斗=try/catch |
| 圆脸小人 | 角色、关系、冲突 | 双人互指=死锁 |
| 电信号（涟漪/电波） | 事件、传播、通知 | 按钮电波=回调 |
| 天平/对比 | 权衡、比较、取舍 | 双杯互倒=类型转换 |

**实证教训**：不加约束时 AI 出图 72% 收敛到「手+容器+序列」。想逼出冷门母题，在 prompt 里写反约束（如"禁止出现手"）。

## 四、换课操作清单

1. `spec.json`：换 `series`、`course`；`s06_title`/`s07_title` 可改（默认「常见陷阱」「动手例子」，历史课可改「史家陷阱」「史料实战」）；`board_prefix` 可指向新出的布局板组
2. 每讲 3 条概念图 prompt：套 `templates/board-prompts.md` 的固定句式，只换「主体」；主体从母题库选，与旁白台词呼应（图里的钥匙 = 台词里的「换钥匙」）
3. 布局板：直接复用 `remotion/public/boards/cs106a_s0*.png`，或按需重出一套
4. TTS：换 `tts/voices/` 下的音色参考 + 显式传 `TTS_REF_TEXT`
5. 渲染：`build_from_pack.py` 自动生成 series 入口，零改动

## 五、质量红线（学科无关）

- 图内零文字（含似字纹理）；单段旁白 8–40s；成片无 >1.2s 断轨
- 槽位几何锁死：板图归一化 1672×941，槽位坐标不再手调
- 隐喻与台词必须互相印证
